# pilots2_re

Восстановленный исходный код проигрывателя Game Maker из второй игры «Братья Пилоты: Дело о
серийном маньяке» (PILOTS2.EXE, 1998). Код на C17 восстановлен по полностью разобранной базе IDA
и собирается MSVC.

Проект продолжает [pilots_re](https://github.com/gr0grig/pilots_re) — восстановленный проигрыватель первой игры
(«По следам полосатого слона», PILOTS.EXE). Обе игры работают на одном движке; вторая — на его
следующей версии. Код второй части получен из кода первой переносом всех отличий, найденных
сравнением двух разобранных баз по каждой функции.

Для работы нужны оригинальные файлы игры: данные игры дописаны в хвост оригинального `PILOTS2.EXE`.

## Что изменилось по сравнению с первой частью

- новая версия формата файла игры и сохранений (0x80000018), настройки — 76 байт вместо 52;
- музыка со звукового компакт-диска через MCI «cdaudio» (дорожка возобновляется после AVI
  и загрузки сохранения);
- камера: вид больше экрана прокручивается за объектом с торможением;
- буфер последних набранных знаков для кодов с клавиатуры;
- пакет графики — новый тег в потоке ресурсов;
- громкость программная (звуки включаются и выключаются, музыка масштабирует ноты);
- справка: поиск по «!» и раздел по номеру;
- 5 новых встроенных функций скриптов (всего 62).

Подробно, по файлам и функциям, — [`SRC\docs\changes.md`](SRC/docs/changes.md).

## Сборка

`SRC\build.bat` — выпуск, `SRC\build.bat debug` — отладочная сборка. Нужны Visual Studio
(MSVC x86) и Windows SDK; пути к ним заданы в начале `build.bat`. Результат — `SRC\out\PILOTS2_RE.EXE`.

Сборка только 32-разрядная: записи файла игры хранят 32-разрядные указатели.

## Запуск

Положите `PILOTS2_RE.EXE` в каталог игры рядом с оригинальным `PILOTS2.EXE` (и каталогом `MOVIES2`).
У собранного EXE нет хвоста с данными, поэтому он читает их из `PILOTS2.EXE` в том же каталоге;
сохранения (`PILOTS2*.SAV`, `PILOTS20.230`) совместимы с оригиналом. Сохранения первой игры
не подходят: у них другая версия формата.

## Отличия от оригинала

Поведение повторяет оригинал, включая его особенности (они отмечены в коде комментариями
«Особенность оригинала»). Сознательно изменено только то, что на современных Windows не работает,
портит память или читает неинициализированные данные:

- буферы путей — `MAX_PATH` вместо 64–128 байт (оригинал падает, если каталог игры лежит глубоко);
- размер рамки окна считается через `AdjustWindowRectEx` (иначе клиентская область меньше 640×480);
- отпускание кнопки мыши, остановившей AVI, не доходит до игры (иначе щелчок по анимации
  проскакивал на элемент под ней);
- стек машины скриптов — собственный массив, а не стек x86;
- `Native_SetCameraParams` обнуляет все четыре числа (оригинал при пустой строке брал первое
  со стека), `GmCd_Play` без привода возвращает `false` (в оригинале — неопределённое значение),
  структуры параметров MCI перед вызовом обнуляются.

Громкость, которую в проекте первой части пришлось сделать программной в обход оригинала, во второй
части программная в самом оригинале — код повторяет его как есть.

Документация по устройству движка — `SRC\docs`.
